# 런타임 기반 검증 기록

2026-11-13에 Linux / GCC / .NET SDK 10.0.113 환경에서 아래 항목을 검증했다. 이 기록은 새 에디터 UI의 시각 검증과 구분한다. 소스·헤더 구조, C# 호스팅, The Forge 실행과 SDK 소비 경로를 대상으로 했다.

| 범위 | 결과 |
| --- | --- |
| 최종 전체 headless 회귀 | 50개 통과. 레벨 UI·애니메이션·격자·기즈모·Inspector·Undo·씬 전환 회귀 포함 |
| 에디터 제외 headless 회귀 | 24개 통과. ECS·씬·JSON·물리·자산·오디오·입력창·보안·샘플·진입점·C#·호스팅 팩 탐색 포함 |
| 독립 에디터 문서·프로젝트·아카이브·빌드 회귀 | 4개 통과 |
| 실제 C# 호스팅 | 생성·업데이트·종료, Transform, 비활성화, 삭제, 예외 격리, 재시작, 잘못된 스레드, 씬 수명 종료, ScriptComponent 저장·로드 통과 |
| Forge X11 GPU 회귀 | 6개 통과: 초기화·잘못된 호출·프레임 반복·2D 드로잉·메시·3D 씬 |
| Forge Wayland GPU 회귀 | 같은 6개 통과 |
| Qt GPU 피킹·합성 | Wayland 3개 통과. 2D/3D 피킹·HiDPI·알파·HDR 투명 배경·스카이박스 합성 포함 |
| 최종 UI 실제 GPU | 새 레벨·애니메이션 작업 공간 및 960×600 화면 캡처, 강제 GPU UI 스모크 통과 |
| `SampleBasic2D` | X11 smoke 실행 정상 종료 |
| 설치 SDK 소비자 | `MinimalGame` 외부 CMake 구성·빌드·실행 통과. 공개 `.inl` 설치 확인 |
| SDK 재배치와 C# 소비자 | 설치 폴더를 이동한 뒤 외부 프로젝트에서 공개 헤더·라이브러리만으로 C# 통합 테스트 구성·빌드·실행 통과 |
| Release 공유 엔진 | 별도 Release 구성에서 `libLuxEngine.so` 빌드 및 설치 SDK 공개 헤더를 사용하는 외부 최소 소비자 링크·실행 통과. 공유 렌더러 패키지 전체 검사는 아님 |
| 뷰포트 편집 | 신규 foundation과 기존 scene UI·2D/3D picking 4개 통과 |
| 생성 게임 | 설치 SDK로 Debug·Release C++/C# 빌드, 실제 GPU 실행, ZIP 생성과 압축 해제 후 재실행 통과 |

생성 게임 검사는 공백·한국어 경로, 기본 경로 밖의 시작 씬, OBJ 메시·PNG 텍스처·HDR 환경 리소스를 포함했다. 각 ZIP에는 62개 파일이 들어갔다. .NET 런타임 전체를 묶는 self-contained 배포 검사는 아니다.

이전 Native Vulkan 오류 주입 전용 검사는 Forge의 기능 검증에 포함하지 않았다. Windows·macOS의 현지 빌드·GPU 실행, 공유 라이브러리 배포 행렬과 모든 기존 GPU 계측·복구 검사가 완료됐다는 의미로 해석하면 안 된다.
