# 기본 메시 모델링

`Editor/Modeling`에 정적 메시 제작 서비스를 분리했다. 기존 CC0 기본 도형과 프로젝트 FBX·OBJ, 엔진 내장 큐브를 같은 모델링 작업 흐름으로 편집한다. 기본 도형 원본은 수정하지 않는다.

## 작업 흐름

모델링 패널에서 기본 도형을 선택해 프로젝트에 배치한다. 메시 오브젝트를 선택한 뒤 Object·Vertex·Face 모드로 전환한다. Vertex는 같은 위치의 UV/법선 경계 정점을 함께 선택하고, Face는 연결된 같은 평면의 삼각형 묶음을 선택한다. 정점·면의 이동·회전·크기 조절은 기존 3D 기즈모를 사용하며 Position을 격자에 반올림하지 않는다.

드래그 중에는 별도의 메시 복사본을 GPU에 미리 보여 준다. 마우스를 놓으면 프로젝트 메시를 저장하고 씬의 메시 참조를 편집 이력 한 건으로 변경한다. Esc, 씬 전환과 유효하지 않은 엔티티 상태는 진행 중인 미리보기를 취소한다. 취소는 에셋이나 Undo 항목을 만들지 않는다.

면 돌출은 선택한 평면 패치를 이동하고 경계에 옆면을 만든다. 같은 재질의 정적 메시 여러 개는 활성 오브젝트의 로컬 좌표로 합칠 수 있다. 반사·비균일 스케일의 위치·법선·면 방향을 보정한다. 삭제되는 오브젝트의 선택되지 않은 자식은 월드 변환을 유지한다. 스크립트·물리·씬 참조가 있거나 부모·자식을 함께 선택한 병합은 명확한 오류로 중지한다.

스킨·모프·애니메이션 모델은 현재 포즈의 독립 정적 복사본을 만든 뒤 편집한다. 원본 계층과 리그는 유지한다. 모델링은 렌더 메시를 다루며 충돌체를 자동으로 재생성하지 않는다.

## 저장과 Undo

결과는 프로젝트의 `Assets/Models/Generated/` 아래 내용 해시를 포함한 OBJ로 저장한다. 기존 파일은 내용을 확인해 재사용하며 덮어쓰지 않는다. 원자적 게시를 위해 프로젝트 폴더는 파일 하드 링크를 지원해야 한다. OBJ에는 위치·법선·UV와 삼각형을 기록하고, 재질·텍스처 연결은 씬의 MeshRenderer에 유지한다. Undo/Redo는 이전·다음 메시 경로를 복원한다. 공유 에셋 파일은 씬에서 되돌리더라도 남겨 다른 오브젝트가 재사용할 수 있게 한다.

서비스는 유한 좌표·인덱스·정점과 출력 크기를 검증하고 실패 시 입력 메시를 변경하지 않는다. 분리된 돌출 면, 비다양체 경계, 특이 변환은 거부한다. 이 기반은 블록아웃과 기본 메시 편집 범위다. 정점·면 삭제와 잘라내기, CSG 불리언, 리토폴로지, UV 편집기, 조각과 리깅 도구는 후속 작업이다.

## 코드 경계

- `MeshModeling.hpp/.cpp`: 메시 읽기·선택 확장·변환·돌출·병합·불변 OBJ 저장을 제공한다. Qt에 의존하지 않는다.
- `ModelingViewport.hpp/.cpp`: 화면 선택·선택 피벗·월드/로컬 기즈모 변환·미리보기와 취소를 처리한다.
- `ModelingWorkspace.cpp`: 팔레트·명령·프로젝트 저장·Undo/Redo를 연결한다.
- `EngineSceneRenderer`: 선택한 엔티티의 지오메트리를 임시 GPU 메시로 교체하며 원본 파일을 변경하지 않는다.

게임 실행과 모델링 편집을 동시에 진행하지 않는다. 정지 상태 Game View는 현재 편집 씬을 계속 표시하고, 모델링 결과를 확정하면 새 메시를 반영한다.
