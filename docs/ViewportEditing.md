# 뷰포트 편집 기반

3D 뷰포트의 격자를 카메라 거리에 맞춰 1·2·5 단위 간격으로 조절하도록 바꿨다. 표시 범위는 원점의 고정 구간 대신 현재 초점 위치를 따라간다. 격자 선분은 카메라 절두체에 먼저 클리핑하고 투영한다. 선의 한쪽 끝이 카메라 뒤로 넘어갔을 때 화면 안에 남은 선까지 사라지던 문제를 고쳤다.

2D 격자도 같은 간격 규칙을 사용하고 기존 ±10000 좌표 제한을 제거했다. 확대·축소와 큰 씬 프레이밍에서도 읽을 수 있는 간격을 유지한다. 편집 뷰포트의 배경은 중립 회색이며 실행 게임의 배경색 설정과 분리한다.

## 카메라와 화면 맞춤

- `F`: 선택 항목의 월드 경계에 화면을 맞춘다.
- `Home`: 씬 전체 경계에 화면을 맞춘다.
- 3D에서 `1` / `3` / `7` / `5`: 정면 / 우측 / 상단 / 원근 방향 프리셋.
- 오른쪽 드래그: 초점 주위를 회전한다.
- 가운데 드래그: 카메라의 오른쪽·위쪽 벡터를 따라 화면을 이동한다.
- 휠: 확대·축소한다.

정면·우측·상단 프리셋에서는 해당 방향의 편집 평면에 격자를 표시한다. 현재 프리셋은 원근 카메라의 방향 프리셋이며 정사영 카메라 전환 기능은 아니다. 카메라의 near/far 범위는 거리에 맞춰 조정한다.

## 3D 기즈모

선택한 엔티티의 피벗에 X(빨강), Y(초록), Z(파랑) 핸들을 표시한다. 이동은 화살표, 회전은 축별 링, 크기는 축별 사각 핸들을 사용한다. 핸들은 화면에서 일정한 크기를 유지하며 장면 위에 표시한다.

기즈모를 누른 뒤 드래그하면 해당 축을 편집한다. `X` / `Y` / `Z`는 축 잠금을 설정하거나 해제한다. 3D 뷰포트에 초점이 있을 때는 이 키를 에디터의 다른 단축키보다 우선한다. 이동 도구의 자유 핸들은 카메라를 향한 평면에서 동작한다. 선택 도구로 오브젝트를 직접 끌 때는 기존 지면 이동을 유지하며, 방향 프리셋에서 지면과 시선이 평행하면 화면 평면을 사용한다. 회전은 월드 축 기준으로 현재 회전 행렬에 적용한다. 크기 핸들은 오브젝트의 로컬 축을 따라 그리며 수평·수직 드래그 모두 해당 축의 화면 방향으로 계산한다.

오브젝트 Position 이동은 격자에 반올림하지 않는다. 2D·3D의 축 이동·자유 이동·다중 선택 모두 소수 좌표를 유지한다. 격자 표시와 타일 편집은 별개다. 회전 중 `Ctrl`을 누르면 15도 단위로 맞춘다. 한 번의 드래그는 한 번의 Undo 제스처를 만든다.

로컬·월드 좌표 모드 전환, 정사영 카메라와 다중 선택 변환은 아직 별도 개발 범위다. 동작하지 않는 메뉴로 표시하지 않았다.

## 회귀 검사

`Editor_viewport_foundation`은 근접 클리핑, 카메라 초점과 회전 방향, 시스템 포인터 논리 좌표에 따른 감도, 원점 밖의 격자, 방향 프리셋과 기즈모의 축 제한·소수 이동·Undo 제스처를 검사한다. HiDPI 구성에서도 같은 논리 입력 계약을 검사한다. 기존 picking 회귀의 near/far 검사는 고정 거리 대신 실제 투영행렬을 기준으로 한다.
