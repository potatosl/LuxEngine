# LuxEditor 개발 체크리스트

LuxEditor는 LuxEngine 라이브러리를 사용하는 별도 2D 편집기다. 화면 구성은 Source 2 Hammer Editor의 중앙 작업 뷰, 계층·속성 패널, 자산 탐색 및 도구 접근 방식을 참고한다. 기능은 작은 묶음으로 구현하고 같은 에디터 PR에 커밋을 추가한다. `[x]`는 실제 구현과 검증이 끝난 항목이다.

프로젝트 템플릿은 각 장르의 시작 장면과 실행 가능한 C++ 예제를 만든다. 프로젝트 내보내기·가져오기는 `.luxpack`, 백업은 `.luxbackup` 형식을 쓴다. 자동 저장본과 백업은 프로젝트의 `.lux/`에 보관하며, v1 프로젝트는 원본 파일을 백업한 뒤 v2로 변환한다. 엔진 버전 검사는 주·부 버전을 비교한다. 종속성은 설치된 CMake CONFIG 패키지로 선언하며 다운로드하지 않는다.

## 2D·3D 확장 기록

위 1–34장은 기존 2D 개발 체크리스트로 유지한다. 아래 항목은 LuxEditor를 2D·3D 공용 에디터로 확장하기 위해 추가한 3D 개발 범위다. `[ ]`는 아직 구현하지 않은 항목이며, P0은 3D 장면을 만들고 저장하는 최소 흐름, P1은 게임 제작에 필요한 기본 도구, P2는 제작 효율, P3은 선택적 고급 기능을 뜻한다. 기존 2D 항목의 완료 상태는 3D 구현 상태를 의미하지 않는다.

조사 기준: [Unreal Level Editor](https://dev.epicgames.com/documentation/en-us/unreal-engine/level-editor-in-unreal-engine), [Unreal Editor Interface](https://dev.epicgames.com/documentation/en-us/unreal-engine/unreal-editor-interface), [Godot 3D Editor Settings](https://docs.godotengine.org/en/stable/classes/class_editorsettings.html), [Khronos glTF 2.0 명세](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html). 상용 엔진의 기능을 그대로 복제하는 목록이 아니라, 3D 게임 제작 흐름에서 필요한 기능을 LuxEngine 규모에 맞춰 우선순위로 나눈 목록이다.

### 이번 인터페이스 개편 현황

- [x] 작업 공간 배치 저장과 기본 배치 복원
- [x] 어두운 작업 공간 색상과 중앙 2D·3D 화면 전환
- [x] 엔티티·프로젝트 파일 검색, 명령 검색, 전체 화면
- [x] 3D 엔티티 경계 프록시 표시·선택·카메라 회전·확대·초점

기존 2장의 체크박스는 원문 보존 요청에 따라 수정하지 않았으며, 이번 구현 현황은 여기서 별도로 기록한다.
