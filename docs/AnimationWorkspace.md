# 애니메이션 작업 공간

애니메이션 편집을 오브젝트 속성에서 분리해 독립 도킹 패널로 만들었다. 보기 메뉴의 애니메이션 항목으로 표시하며 위치 이동·분리·레이아웃 저장을 지원한다. 구현은 `Editor/Animation/Private/LuxEditor/Animation/AnimationWorkspace.cpp`에 모았다.

씬에서 대상을 선택하고 패널의 애니메이션 사용을 켜면 Transform 클립을 생성한다. 클립 이름·길이·반복을 편집하고, 시간 눈금과 키 마커를 보면서 재생·일시정지·정지·이전/다음 프레임 이동을 사용한다. FPS는 에디터의 재생 갱신과 프레임 이동 단위이며 엔진 클립은 초 단위 시간을 사용한다. 긴 클립의 프레임 이동도 슬라이더 해상도로 양자화하지 않는다.

오브젝트 변환을 편집한 뒤 현재 변환 키 추가로 위치·회전·크기를 함께 기록한다. 키 목록에서 선택한 키를 삭제하거나 Delete로 지울 수 있다. 시간 이동과 편집은 기존 Undo/Redo에 연결했다. 재생 중 선택·씬을 변경하거나 패널을 닫으면 재생을 중지한다.

현재 엔진의 오브젝트별 단일 Transform 클립을 편집한다. 스프라이트 시트·본 애니메이션과 속성별 독립 곡선 편집은 엔진 확장 후 연결할 기능이며, 구현 위치에 개발 중 주석을 남겼다.

씬 뷰포트에서는 기본 선택 도구로도 직접 드래그한다. 2D는 월드 XY, 3D는 XZ 평면에서 포인터를 따라 이동하며 Shift를 누르면 XY 평면을 사용한다. 부모 변환 아래에서도 월드 이동을 로컬 변환으로 반영하고 한 번의 드래그를 하나의 Undo로 기록한다.

격자는 배경에 그린 뒤 투명 배경의 엔진 오브젝트 영상을 합성한다. 불투명 오브젝트가 격자를 가리고 반투명 오브젝트는 알파에 맞게 합성한다. 타일 경계선과 비선택 3D 프록시를 GPU 영상 위에 덧그리던 동작도 제거했다.

검증: 에디터 headless 20개, 기본 선택 도구의 2D·3D 드래그, 별도 애니메이션 패널의 클립·프레임 이동·재생 제어, 긴 클립의 프레임 정밀도, 불투명 스프라이트의 격자 가림과 GPU 선택·HiDPI 회귀를 확인했다.
