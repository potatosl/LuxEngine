# 애니메이션 작업 공간

레벨의 오브젝트 속성 패널과 애니메이션 제작 화면을 분리했다. 상단 작업 공간에서 **애니메이션**을 선택하면 대상 클립, 2D·3D 프리뷰, 선택 키 속성, 도프 시트가 한 화면에 표시된다.

화면 구성은 [Unreal Animation Sequence Editor](https://dev.epicgames.com/documentation/unreal-engine/animation-sequence-editor-in-unreal-engine?lang=en-US)의 프리뷰·Details·타임라인과 [Unity Animation window](https://docs.unity.com/en-us/engine/7000.0/manual/animation-section/animation-mecanim/animation-clips/animation-editor-guide)의 도프 시트·곡선 작업 흐름을 참고했다. 이 문서는 LuxEditor에 실제 연결된 기능만 설명한다.

## 클립과 키 편집

1. 레벨 Outliner에서 변환이 있는 오브젝트를 선택한다.
2. 애니메이션 작업 공간을 열고 **새 변환 클립**을 누른다. 첫 키는 현재 변환으로 생성된다.
3. 재생 헤드를 이동하고 오브젝트의 변환을 조절한 뒤 **현재 변환 키 추가**로 기록한다.
4. 키 목록이나 도프 시트에서 키를 선택하면 오른쪽에서 시간, 위치, 회전, 크기를 편집할 수 있다. 회전 입력은 도 단위를 사용한다.
5. 도프 시트의 키를 끌면 설정한 FPS의 프레임 간격으로 시간이 맞춰진다. 다른 키와 같은 시간으로 옮기는 동작은 기존 키를 덮어쓰지 않도록 거부한다.

**자동 재생**은 게임 실행 시 재생 여부만 바꾸며 키를 보존한다. 클립 삭제는 별도의 휴지통 버튼으로 실행하고 Undo로 복원한다. 저장 아이콘은 클립이 담긴 씬을 저장한다.

키 추가·삭제·값 변경·시간 이동과 시간 스크러빙은 기존 씬 Undo/Redo에 연결했다. 긴 클립의 한 프레임처럼 슬라이더의 1/1000 구간보다 짧은 시간도 실제 클립 시간으로 기록한다.

## 타임라인 탐색과 미리보기

- 재생·일시정지, 정지, 이전·다음 프레임 버튼을 제공한다. 정지는 0초로 돌아간다.
- 타임라인에 포커스가 있을 때 `Space`는 재생·일시정지, 좌우 화살표는 한 프레임 이동, `Delete`는 선택 키 삭제다. 키를 삭제해도 씬 오브젝트는 유지된다.
- 시간 눈금을 누르거나 끌면 재생 헤드를 움직인다. 도프 시트의 빈 시간에 두 번 누르면 현재 변환 키를 추가한다.
- 확대 입력과 수평 스크롤바로 시간 범위를 탐색한다. 마우스 휠은 수평 이동, `Ctrl`+휠은 확대·축소다.
- **위치 곡선**은 위치 X·Y·Z의 실제 선형 보간을 각각 빨강·초록·파랑으로 표시한다.
- 선택 대상의 렌더러에 따라 초기 2D·3D 프리뷰를 고른다. 초점 버튼은 대상을 다시 화면에 맞춘다.

## 현재 엔진 범위

현재 엔진 데이터는 오브젝트별 Transform 클립 하나와 선형 보간을 지원한다. 위치·회전·크기는 하나의 엔진 키에 함께 기록된다. 도프 시트의 채널 표시가 독립적인 채널 데이터 형식을 뜻하지는 않는다.

스프라이트 시트, 본·스켈레톤, 독립 클립 에셋, 애니메이션 상태 머신, Bezier 접선, 채널별 독립 키는 아직 연결되지 않았다. 지원되는 것처럼 동작하지 않는 메뉴를 표시하지 않는다.

## 검증

`Editor_animation_timeline`은 흰색 Qt Base 팔레트가 남아 있어도 다크 타임라인 대비가 유지되는지, 키 선택과 프레임 스냅 드래그가 동작하는지 검사한다.

`Editor_animation_workspace`는 전용 작업 공간 전환, 선택 키 값·시간 편집, 드래그 Undo, 긴 클립의 프레임 정밀도를 검사한다. `LUX_ANIMATION_CAPTURE`에 PNG 경로를 지정하면 실제 작업 화면도 저장한다.
