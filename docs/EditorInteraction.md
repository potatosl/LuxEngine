# 에디터 선택과 변환 제스처

## 통합 선택

선택 목록과 활성 오브젝트는 `EditorDocument`가 씬 탭별로 관리한다. 목록의 순서를 보존하고 마지막 항목을 활성 오브젝트로 사용한다. 기존 `Select()`와 `GetSelected()`는 단일 선택 호출자와 호환된다. 삭제된 ID는 조회와 적용 시 제외한다. 선택·좌표계·피벗 설정은 에디터 상태이며 씬의 변경 표시나 파일 데이터가 아니다.

- 일반 클릭은 오브젝트를 선택한다. 이미 선택한 오브젝트를 잡으면 선택 묶음을 유지한 채 이동할 수 있다.
- Shift 클릭은 추가, Ctrl 클릭은 선택 여부 전환이다.
- 빈 공간에서 드래그하면 사각형 선택을 수행한다. Shift는 추가, Ctrl은 영역 내 선택 여부 전환이다. 작은 포인터 흔들림은 사각형 조작으로 처리하지 않는다.
- Outliner의 복수 선택, 2D/3D 뷰포트의 강조 표시, Details의 선택 개수와 활성 오브젝트가 같은 목록을 사용한다.
- Details에 표시되는 값은 활성 오브젝트 기준이다. Transform 필드 편집은 선택한 오브젝트들의 해당 로컬 필드에 일괄 적용한다. 다른 컴포넌트 편집은 활성 오브젝트에 적용한다.

## 다중 변환

뷰포트 상단에서 월드/로컬 좌표계와 피벗을 선택한다.

| 피벗 | 회전·크기 조절 기준 |
| --- | --- |
| 중앙 | 선택된 오브젝트 원점들의 평균 |
| 활성 | 마지막으로 선택한 활성 오브젝트 원점 |
| 개별 | 각 오브젝트의 원점 |

변환은 제스처 시작 상태에서 계산한다. 이전 마우스 이벤트의 결과를 다시 확대·회전하지 않아 반복 프리뷰의 누적 오차를 피한다. 부모와 자식을 함께 선택하면 최상위 선택 루트에 한 번만 적용하여 자식이 두 번 움직이지 않게 한다.

엔진의 Transform은 TRS 표현이다. 회전된 개체에 월드 비균일 크기를 적용하거나 비균일 부모 아래에서 회전하면 표현할 수 없는 shear가 필요할 수 있다. 이런 변환은 값을 근사하거나 일부 오브젝트만 변경하지 않고 직전 유효 프리뷰를 유지하며 거부한다. 로컬 좌표나 균일 크기를 사용하면 된다.

## 확정과 취소

마우스 버튼을 놓으면 제스처 하나를 Undo 명령 하나로 확정한다. 움직이지 않은 제스처와 선택 변경만으로는 편집 명령을 만들지 않는다.

Esc, 포커스/마우스 캡처 유실, 도구·작업 공간·씬 전환은 진행 중인 변환을 취소한다. 원래 데이터·선택·변경 표시를 복원하고 Undo 기록을 추가하지 않는다. 입력 시스템이 release 이벤트를 놓친 경우도 다음 이벤트에서 감지해 정리한다. Undo/Redo를 진행 중인 제스처에서 실행하면 우선 그 제스처를 취소한다.

제스처는 원래 씬 탭과 수명 토큰을 추적한다. 씬이 교체된 뒤 늦게 도착한 마우스 이벤트는 새 씬을 수정하거나 오래된 스냅샷으로 덮어쓰지 않는다. Undo/Redo는 변환과 함께 전체 선택 목록도 복원한다. 제스처 도중 자동 저장과 편집용 씬 스트리밍은 미룬다.

## 검증

`Editor_selection_core`는 순서·활성 선택·탭·삭제된 ID·피벗·계층·원자적 변환·수명 토큰을 검사한다. `Editor_interaction_2d`와 `Editor_interaction_3d`는 실제 포인터 이벤트로 클릭·사각형·변환·취소를 검사한다. `Editor_interaction_integration`은 실제 에디터 창에서 Outliner·Details·뷰포트 동기화, 일괄 필드 편집, 한 번의 Undo, Esc·포커스·씬 전환 취소와 dirty 상태를 검사한다. 이동하지 않은 제스처 취소 시 전체 선택 복원, 제스처 중 씬 간 이동 시 원본 삭제와 프리뷰 값 유출 방지, 두 씬의 Undo 복원도 검사한다.

이 묶음에는 에셋 드래그 배치, 표면 스냅, 프리팹은 포함하지 않았다.
