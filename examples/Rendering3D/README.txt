LuxEngine 3D 렌더링 비교

Legacy.lux: 기존 렌더링. 기존 씬의 외관을 유지하는 기준입니다.
PbrDirect.lux: 기본색·금속성·거칠기와 방향광의 PBR 반응입니다.
PbrEnvironment.lux: 내장 환경의 반사와 HDR·ACES 톤 매핑을 추가합니다.
PbrShadows.lux: 방향광 그림자를 추가합니다.

각 씬은 같은 모델과 배치를 사용합니다. 윗줄은 금속성 1, 아랫줄은 금속성 0이며,
왼쪽부터 거칠기가 0.1, 0.5, 0.9입니다. 인스펙터에서 재질 값을 바꾸고 시점을
이동하면 하이라이트와 환경 반사의 변화를 확인할 수 있습니다.
OBJ는 인접한 MeshFoundation/Assets/SmoothSphere.obj를 참조합니다.
예제를 이동할 때 두 예제 디렉터리의 상대적인 위치를 유지해 주세요.

기존 씬에 적용하려면 씬 설정에서 3D 모드를 PBR로 바꿉니다.
새 프로젝트의 '3D PBR' 템플릿도 같은 경로를 사용합니다.
기존 v1~v5 씬은 Legacy로 열리며, 새 렌더링 설정은 v6으로 저장합니다.
구버전 에디터는 v6 씬을 읽을 수 없습니다.

씬 설정에서 방향광·환경 강도·환경 회전·스카이박스·톤 매핑을 조절합니다.
외부 환경은 2:1 비율의 Radiance .hdr 이미지로 지정합니다.
파일 크기는 최대 64 MiB, 디코딩 데이터는 최대 256 MiB입니다.
입력 파일 수정 후 '환경 다시 불러오기'를 누르면 재처리를 시작합니다.
환경 전처리 중에는 기본 환경색 또는 기존 정상 자원을 표시합니다.
외부 환경을 배포하려면 프로젝트 Assets 안에 넣어 주세요.

그림자는 방향광 1개를 지원하며 기본 해상도는 2048입니다.
1024/2048/4096을 선택할 수 있습니다. 기본 적용 영역은 카메라 초점을 중심으로
폭과 높이가 50월드 단위인 영역입니다. 영역 밖에는 그림자를 적용하지 않습니다.
기본 깊이 바이어스는 0.0005, 법선 바이어스는 0.02월드 단위입니다.
장면의 크기에 따라 바이어스와 적용 영역을 조절할 수 있습니다.

환경 반사는 미리 계산한 확산·정반사 환경맵과 BRDF LUT를 사용합니다.
주변 물체를 실시간으로 반사하는 기능과 캐스케이드·점광 그림자는 포함하지 않습니다.
재질의 부분 투명 블렌딩·정렬과 노멀맵은 별도 후속 기능입니다.

성능 측정은 Release LuxEngineTests.exe render_bench로 실행합니다.
저장소 루트에서 실행하면 build/rendering-benchmark.json을 생성합니다.
1080p에서 구체 100개와 바닥을 그리며, 그림자 끔/1024/2048/4096 각각
준비 60프레임 뒤 600프레임의 CPU·GPU 시간과 GPU 할당량을 기록합니다.
환경 전처리 시간은 프레임 측정과 따로 기록합니다.
